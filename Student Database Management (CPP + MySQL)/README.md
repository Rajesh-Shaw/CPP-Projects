# 🎓 Student Database Management (C++ + MySQL)

### 🧠 Overview
A simple console-based CRUD system that performs Create, Read, Update, and Delete operations on a MySQL student table.

---

### 🧩 Concepts Used
- MySQL Database integration in C++
- OOP (Class-based structure)
- Query building and execution
- Basic error handling

---

### ⚙️ Features
| Feature | Description |
|----------|--------------|
| Add Student | Insert new student record |
| View Students | Fetch all students from DB |
| Update Student | Modify name, age, or grade |
| Delete Student | Remove student by ID |

---

### 💻 How to Run
1. Import `student_db.sql` into MySQL.
2. Update your MySQL password in `main.cpp`.
3. Compile using:
   ```bash
   g++ main.cpp -o student -lmysqlclient
4. Run:
    ./student
    ```
