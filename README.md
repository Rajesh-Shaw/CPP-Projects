# 🚀 CPP Projects

A curated collection of **C++ projects** developed for learning, practice, and demonstration.  
Each project is organized in its own folder with its source code and individual documentation.

---

## 📘 Overview
This repository contains a variety of **C++ console-based and mini-system projects** — from basic programs to more advanced simulations.  
Perfect for **students, beginners, and enthusiasts** to strengthen their programming and problem-solving skills.

---

## 🧩 Projects Included

| 🧱 Project Name | 📝 Description | ⚡ Difficulty |
|-----------------|----------------|----------------|
| **Calculator App** | A console-based calculator supporting basic arithmetic operations. | 🟢 Beginner |
| **Student Management System** | Manage student data, marks, and averages. | 🟡 Intermediate |
| **Bank Management System** | Simulate simple banking operations (deposit, withdraw, check balance). | 🟡 Intermediate |
| **Library Management System** | Manage books, members, and borrow/return records. | 🟡 Intermediate |
| **Hotel Reservation System** | Book and manage rooms with simple file handling. | 🟡 Intermediate |
| **Chat Application** | Basic text-based chat between two users (console simulation). | 🔴 Advanced |
| **Tic-Tac-Toe Game** | Two-player console game with win/draw detection. | 🟢 Beginner |
| **Rock-Paper-Scissors Game** | Play against computer with random choice logic. | 🟢 Beginner |
| **Number Guessing Game** | Guess the secret number with hints and scoring system. | 🟢 Beginner |
| **ATM System** | Simulated ATM interface for deposits, withdrawals, and PIN validation. | 🟡 Intermediate |
| **Quiz Game** | Multiple-choice quiz with levels, scoring, and timer simulation. | 🟡 Intermediate |
| **To-Do List Manager** | Create, update, mark, and delete daily tasks — saved to file. | 🟢 Beginner |

## 🛠️ Technologies Used
- **Language:** C++  
- **Compiler:** `g++`, `clang++`  
- **IDE:** Visual Studio Code, Code::Blocks, or any preferred C++ IDE  
- **Libraries:** Standard C++ STL  
- **Concepts Covered:** Loops, Functions, OOP, File Handling, Arrays, Logic Building

## ⚙️ How to Run Any Project
1. Open terminal or PowerShell  
2. Navigate to the desired project folder:
   ```bash
   cd "To-Do List Manager"
3. Compile the project:
   ```bash
   g++ main.cpp -o todo.exe
4. Run the executable:
   ```bash
   ./todo.exe
