# 🏢 Employee Management System (C++ OOP Project)

## 📘 Overview
A console-based Employee Management System built using **Object-Oriented Programming (OOP)** concepts like **Inheritance**, **Polymorphism**, and **Encapsulation**.

This project allows adding, viewing, searching, and managing different types of employees such as **Managers**, **Developers**, and **Interns**, each with unique salary structures.

---

## 🚀 Features
- Add Employee (Manager / Developer / Intern)
- Calculate role-based salary dynamically
- View all employees in tabular format
- Search employee by ID
- Data saved and loaded from file (`employees.txt`)
- Uses **Polymorphism**, **Virtual Functions**, and **File I/O**

---

## 🧠 OOP Concepts Used
| Concept | Description |
|----------|--------------|
| **Encapsulation** | Employee data is hidden with private members |
| **Inheritance** | Derived classes inherit from `Employee` |
| **Polymorphism** | Virtual functions for salary calculation |
| **Abstraction** | Common interface for all employee types |
| **File Handling** | Persistent employee records using text files |

---

## ⚙️ How to Run
```bash
g++ main.cpp -o EmployeeSystem
./EmployeeSystem

```
