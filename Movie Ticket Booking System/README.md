# 🎬 Movie Ticket Booking System (C++)

A console-based movie ticket booking system built using **C++ OOP principles** and **file handling**.

---

## 📘 Overview
This project allows users to view movies, book tickets, cancel bookings, and view all booking records — all with persistent data saved in files.

---

## 🧩 Features
- View list of movies with timing, price, and available seats  
- Book movie tickets (auto cost calculation)  
- Cancel ticket booking  
- View all bookings  
- Data stored persistently in `movies.txt` and `bookings.txt`

---

## 🛠️ Concepts Used
- Classes & Objects  
- Constructors  
- File Handling (Read/Write)  
- Encapsulation  
- Loops & Decision Control

---

## ⚙️ How to Run
```bash
g++ main.cpp -o movie
./movie
```
